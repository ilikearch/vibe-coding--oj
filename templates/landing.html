使用流程

只需四步，即可完成 C++ 代码的在线提交与自动判题

1

注册账号

一键创建账号，即刻开始编程之旅。支持安全密码哈希保护。

2

编写代码

在在线编辑器中编写 C++ 代码，支持自动缩进、代码模板与键盘快捷键。

3

提交判题

一键提交，沙箱编译执行，比对输入输出。支持时间与内存限制。

4

查看结果

实时反馈 AC/WA/CE/TLE/RE 状态，对比期望输出与实际输出差异。

核心能力

C++ 判题

提交 g++ 代码，基于 stdin/stdout 比对自动判定。支持多种判题状态反馈。

三层沙箱

rlimit 资源限制 + seccomp 系统调用过滤 + chroot 目录隔离，杜绝恶意代码。

用户系统

注册登录、Session 管理、bcrypt 密码哈希，安全可靠。

管理后台

在线管理题目、编辑 Markdown 描述、配置测试用例，一切尽在掌握。

时间限制

可配置的 CPU 时间限制，自动检测 TLE 超时。默认 2 秒时限。

Markdown 题目

题目描述支持 Markdown 格式，代码块、列表、表格随心编排。

技术栈

判题引擎

g++ 编译，fork/exec 子进程执行，rlimit + seccomp + chroot 三层安全沙箱

g++ seccomp rlimit chroot

前端界面

HTML5 CSS3 Vanilla JS SVG

安全机制

bcrypt 密码哈希、Session Token 认证、seccomp 系统调用白名单、资源限制

bcrypt Session Sandbox ACL
